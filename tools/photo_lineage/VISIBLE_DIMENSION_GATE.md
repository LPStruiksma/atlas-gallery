# Bounded visible RAW dimensions before sensor array access

The metadata-only `visible_bayer_calibration` now validates the decoder-reported **visible** width/height before any sensor array access: each dimension must be 96–12,000 and the product at most 48 million pixels. Missing, boolean, zero, oversized and malformed values fail closed. This matches the input ceiling in `bayer_luminance.py` and prevents a caller from proceeding with a clearly incompatible visible mosaic. It is **not a pre-decompression memory limit**: a malicious or malformed RAW may already have been decompressed by the external decoder. Actual RAW decoding still requires a separately reviewed isolated subprocess with OS memory/CPU limits, trusted source curation and license review. No rawpy import, file access, network or private photos are involved. Six synthetic dimension cases extend the existing fake-decoder suite.
