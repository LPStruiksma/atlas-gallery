## Task and UX contract

From an existing album, Pictures month, search result or Photo DNA group, enter a source-ordered frozen review deck with the one-thumb actions Keep / Skip / Stage Trash; resume reliably per source/month and compare or file by deliberate choice. **Keep** is a durable, identity-checked non-destructive review decision. **Skip** is transient. **Stage Trash** is transient until the **app** confirmation, exact-URI MediaStore preflight and a **separate Android system** Trash approval succeed. Review progress is source-local, not global. Changes or permission loss invalidate the pending action, never silently delete. Large media collections are lazy/paged. Search input/IME remains on the existing Search home, not in the deck.

Source precedent: [Quiet Frame v3](QUIET_FRAME.md) owns placement, tokens and held sphere. [Samsung parity spec](../product/SAMSUNG_PARITY_SPEC.md) owns supported feature behavior, not Samsung layout. [Declutter Studio](../DECLUTTER_STUDIO.md) owns recoverable-Trash safety. Material 3's documented sheet affordance and the existing ATLAS deck are the layout/interaction anchors. Slidebox, Swipewipe and Google Photos are *inspiration named by the issue*, not verified placement references or a license to copy.

| Reference behavior / source | Adaptation | Difference, risk and evidence limit |
| --- | --- | --- |
| Existing ATLAS Declutter: Keep, stage, review, first confirmation, MediaStore check, Android approval | Extend only source scopes, progress and resume; retain exact metadata preflight and generation guard | No raw deletion, silent Trash, background cleanup or persistent stage |
| Android system [recoverable Trash request](https://developer.android.com/reference/android/provider/MediaStore#createTrashRequest(android.content.ContentResolver,java.util.Collection,boolean)) | App confirmation explicitly warns that Android will ask again; issue system request only after successful preflight | System dialog wording/theme is owned by Android, not rendered or reproduced as an ATLAS-owned sheet |
| Quiet Frame v3: solid lapis brand-fill, readable brand-text and 48 dp targets | Selected overflow row is brand-fill with on-brand label; other rows on surface | No extra highlight token, tinted grey, Samsung pill or new floating navigation |
| Android accessibility and system insets | Content is reflowed under 200% fonts, secondary actions reachable by scroll/TalkBack, top/back and bottom primary controls >=48 dp | Synthetic frames are measurable plans, not a device accessibility pass |

## Exception and input contract (applies in both themes)

| Case | Initial focus / readable copy | Layout, action bounds and cancellation | Outcome / next screen |
| --- | --- | --- | --- |
| **Loading, index or video decode** | TalkBack: “Preparing review”; held sphere on arc and a plain live progress count | Use the deck photo well x18..342, y132..424; disable all mutating controls (retain their 48 dp slots); Back remains x8..56, y24..72. Do not launch an extra player per card | Decode completion shows deck; retryable failure shows “Could not prepare this review”, 56 dp Retry / Back actions in the exception layout |
| **Empty / no Search matches** | Announce scope and “No photos to review” | Empty frame action bounds x18 y518/587, 324 × 56; if launched from Search, Back restores query and focus to results | No staged request and no phantom progress |
| **Completed** | “All items reviewed”, scope count, no deleted-file claim | Complete frame same 56 dp actions; no automatic restart | Return to source or deliberately start a different review |
| **Permission restricted at entry** | “Some photos are unavailable; reviewing only accessible items” | Enter partial subset only after explicit acknowledgement; denominator recomputed for accessible source | If grant revoked during review, block mutation; permission frame offers Settings via system permissions and Back |
| **Changed row / pending verification failure** | “Some items changed; no files were moved to Trash” | Changed frame 56 dp restart / Back; invalidate stage; never offer Android prompt from stale scope | Re-snapshot from MediaStore or cancel without effect |
| **Android 10** | “Trash is unavailable on this Android version” | Keep / Skip and allowed non-destructive compare/file stay available; Stage Trash commit disabled without a fake OS confirmation | No `createTrashRequest`, no delete |
| **More than 200 staged** | “Review in groups of up to 200” | 48+ dp group/Back actions; split only after deliberate selection | No automatic truncation of selected URIs |
| **Large library, 150,000 items** | “Reviewed n of m” only for frozen currently eligible scope, not total across sources | Same deck geometry, lazy item window and cancelable prefetch; never render all media or allocate players per item | Scroll/sort may rebase only by new explicit snapshot |
| **Start again** | “Clear review progress?” with plain disclaimer | Reset frames x18 y518/587 w324 h56; Cancel and Back retain Keeps; affirmative only clears that source's saved Keep keys | Fresh source ordered deck; untouched media |
| **IME, keyboard and insets** | Search uses the existing editable search field, not the deck | Dismiss keyboard before opening deck; 24 dp synthetic safe top/bottom, actual dynamic insets measured on device; all primary actions above y756; 48 dp minimum touch targets | Back/IME dismissal returns to unchanged search scope |
| **200% type, RTL, TalkBack, reduced motion** | Focus order: Back → source/progress → media → Undo/Review staged (when available) → Keep → Skip → Stage Trash → confirmation/actions; announce counts before actionable mutations | Stack primary choices on the large-text frame; allow secondary scrolling and focus reachability, honor RTL text order, preserve source order; reduced motion cuts immediately with no automated flip/fade | No hidden decision, trapped focus or gesture-only action |

**Two approvals, not three user-visible steps:** `Confirm 12 items` records the **ATLAS** affirmative decision. The app then **privately** re-queries exact MediaStore content URIs and original id/name/physical path/bytes/nonzero modification date/trashed status for 1–200 distinct items, checks session generation and permission, and stops on any mismatch. Only a successful preflight invokes the **separate Android-owned recoverable Trash prompt**, which may be denied or cancelled. Denial/cancellation leaves originals untouched; Android-success exits the frozen deck and rebuilds MediaStore. Do **not** show “re-query MediaStore”, “preflight”, “URI” or implementation step numbers in any user copy; the OS dialog wording is system-dependent and cannot be asserted by these mock-ups. The estimate does not promise immediate freed disk space.
