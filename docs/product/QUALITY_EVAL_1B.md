Research access, a code licence, a mirror licence, or the absence of an explicit ban does not by itself establish these rights. ## Frozen protocol v1 (before any measurement)

### Question and strata

The primary question is whether model-free whole-photo signals agree with human preference on two versions of the **same underlying scene**, not whether one unrelated photo is more beautiful, nor whether an image is disposable. Reference-relative degradation or restoration fidelity, general no-reference quality, aesthetic appeal and true best-shot/keeper preference are distinct tasks. Report them separately; no pooled cross-dataset score. Use reference-matched variants only for the primary proxy stratum; real same-stack human keeper judgments, if separately licensed and available, are the target stratum. A KonIQ/AVA cross-content comparison is an explicitly secondary proxy only; never feed those pairs to the keeper as known stacks. No face detection or face preference inference in this protocol.

### Acquisition, sampling and leakage

1. After approval, pin dataset version, official download URLs, expected file digests, licence manifest (creator/source/licence/derivative and permitted use), and scoring commit. Download into a user-chosen directory outside the git checkout; verify digests and refuse missing/ambiguous rights. No public image, identifier, label, face data, EXIF or asset-level result; publish only aggregate counts, methodology, cited dataset and code revision. Keep restricted provenance locally. No remote model/API.
2. Use official held-out test split where available and ensure no shared original/scene, crop, duplicate or near duplicate with development or calibration data. Group all variants by original reference/scene before selection. Where no split exists, deduplicate by exact decoded-pixel hash and documented near-duplicate grouping (64-bit grayscale DCT perceptual hash, Hamming distance <= 6, transitive closure; review apparent false merges before freezing). Assign groups by SHA-256 of UTF-8 "atlas-quality-v1|"+stable group ID, first 64 bits big-endian modulo 5; bucket 0 development, 1 calibration, 2–4 untouched test. Never split groups or tune after examining test labels/results. Official splits take precedence; if any known overlap exists exclude the affected test group and count it. No use of models trained on the benchmark; record any known prior exposure. Development/calibration not needed for this frozen scorer; keep reserved anyway.
3. Include only successfully licence-verified, decodable RGB/sRGB photographs with valid labels and dimensions at least 16×16, valid pair membership and distinct pixel hashes. Exclude missing labels, unknown licence, non-photographic assets, exact duplicates, invalid/unsupported decode and known leakage; count each exclusion once using this order (licence, leakage, label, membership, decode, duplicate). Do not exclude a valid pair merely because its scorer abstains, misses or disagrees. For keeper safety, separately tag intentional blur, unusual exposure, face/eye ambiguity, crop/edit/distinct content, screenshots/text and unknown stack status before seeing scores; missing context is not assumed safe.
4. Construct canonical unordered pairs (lexicographically sorted stable IDs). Same-reference datasets: within each original, form all eligible unordered pairs with available human labels. For cross-content proxy only, pair disjoint held-out groups by SHA-256 rank and adjacent IDs in rank order, one image per group (lowest hash of image ID), dropping an odd final group. Never fabricate same-scene identity. To bound same-reference work, select up to 20 eligible decisive pairs per original by ascending SHA-256 of UTF-8 "atlas-quality-v1|pair|"+canonical IDs separated by a NUL; cap at 2,000 pairs overall by hash-ranked reference round-robin, taking one pair per reference per round. Record eligible and sampled counts, group counts, distortion family and label-gap bins. Keep human ties separately, up to 20 per group using the same ordering and separate 2,000 cap. No selection by predicted score.
5. Freeze presentation order independent of the model. In each stratum, sort decisive sampled pairs by the pair hash; alternate whether the human winner is A or B starting with A, giving winner-side imbalance at most one. For ties use hash parity. Order balancing only affects presentation, never the chosen pair or scorer. Report A/B counts, human gap bins, family distribution and per-reference group sizes. Do not reweight to conceal difficulty or compare strata without their composition.

### Ground truth and ties

Use the original human measurement, not a network score. On AVA use weighted average of the ten rating-bin counts; KonIQ use raw MOS on the 1–5 scale, SPAQ use overall MOS with range from its release, KADID use the published DMOS (higher means better). For bounded ordinal-score proxies define normalized gap (score A minus score B)/(published maximum minus minimum); absolute gap < 0.10 is a human tie, otherwise the higher score wins. Report gap bins [0.10,0.20), [0.20,0.40), >=0.40. On PIPAL use within-reference Elo difference, and convert to expected A preference via 1/(1+10^((Elo_B-Elo_A)/400)); explicitly derived, not raw votes. PieAPP use observed preference probabilities from the official test labels, not inferred train/validation probabilities. For probability labels, p >= 0.60 means A, p <= 0.40 means B, otherwise tie; gap bins use abs(2p-1) with thresholds 0.20, 0.40, 0.80. For future direct keeper votes use the same probability rule with at least five independent votes per pair, excluding explicit human abstentions from the denominator and recording their count. Report original rating/vote counts where available; do not imply the same annotators rated both MOS images. Unknown label range, out-of-range value, missing vote denominator or incomparable labels means exclusion. No ties forced into wins.

### Scorer and endpoints

Use the merged [PhotoQualitySignals.kt](https://github.com/LPStruiksma/atlas-gallery/blob/main/app/src/main/java/nl/atlas/gallery/featurecuration/quality/PhotoQualitySignals.kt) on predecoded ARGB8888 at native supplied dimensions (no extra resize; record decoder/version, colour conversion and orientation policy, apply EXIF orientation locally then discard EXIF; opaque images use alpha 255). Record pinned source SHA. Compare per-image Laplacian variance (larger indicates edge energy; not inherently better); difference below 0.002 or unknown is abstention. Separately report exposure guard pass/fail (dark and light fractions each <=0.25, spread >=0.08); no invented exposure ranking. Face/eye/smile signal agreement is NOT MEASURED without separately authorised human labels and detector inputs.

For genuine known stacks use [ConservativeKeeper.kt](https://github.com/LPStruiksma/atlas-gallery/blob/main/app/src/main/java/nl/atlas/gallery/featurecuration/quality/ConservativeKeeper.kt) unchanged on two candidates, with no synthetic user/RAW preference and with hard-negative/distinct flag when known or context is uncertain. Its hard-negative guard precedes preferred-edit handling; missing blur/exposure, either unsafe exposure or blur delta below 0.002 abstains. For same-reference artificial distortions with confirmed same content, report separately as a technical proxy; no assumption that a reference-relative label is a keeper vote. No threshold fitting. No recommendation to delete, hide or automate anything.

If the actual Kotlin evaluation harness is unavailable, an optional independently tested Python port must implement the same sRGB linearization, stride/alpha validity, ceil(max edge/256) sampling, histogram rounding and percentile rules, Welford variance and minimum-sample rules. Record the port revision, decoder and synthetic parity checks; call all results **Python analogue**, never Kotlin. The existing timing-only Laplacian harness is not such a full port. Kotlin-path agreement remains NOT MEASURED until actual Kotlin evaluation is executed.

### Counts and uncertainty

For each dataset, stratum and scorer report total eligible, exclusions by reason, sampled human-decisive D, human ties T, distinct original groups G, decisive correct C, wrong W and scorer abstained A (D=C+W+A). Report coverage (C+W)/D, conditional agreement C/(C+W), all-decisive agreement C/D (abstentions not correct), and error among all decisive W/D. On human ties separately report abstention rate and forced-choice count; do not count tie agreement in decisive accuracy. Zero denominator -> NOT MEASURED (not 0%). Compare chance 0.5 and always-abstain baseline (coverage 0, conditional accuracy undefined); report results by gap, distortion family, hard-negative and resolution strata when support permits. No post hoc pass threshold or safety claim.

Use cluster bootstrap for 95% percentile intervals (2,000 replicates, NumPy PCG64 seed 1089, record version): resample G original/scene groups with replacement, G draws per replicate, include all sampled pairs from every drawn group with multiplicity; recompute ratios on each replicate, endpoints at empirical 2.5/97.5 percentiles using linear interpolation. Cross-content disjoint pairs are independent bootstrap units because each group appears at most once. Report effective group count and undefined replicate count; with fewer than 20 groups or fewer than 1,900 finite replicates, interval NOT MEASURED (insufficient support). Use identical resamples when comparing scorers and bootstrap paired metric differences. This addresses repeated-reference dependence, not all annotator or selection uncertainty. Report counts alongside intervals, not a claim about all gallery users.
